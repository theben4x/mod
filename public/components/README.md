# תמונות רכיבים

הניחו כאן תמונת מוצר אחת לכל רכיב, בשם **המזהה (`id`) של הרכיב** בדיוק כפי שהוא מופיע ב-`data/components/*.ts`.

```
public/components/rtx-5090.png
public/components/ryzen-7-9800x3d.webp
public/components/samsung-990-pro.jpg
```

- פורמטים נתמכים: `.webp` · `.png` · `.jpg` · `.jpeg` · `.avif` (מומלץ `.webp` או `.png` עם רקע שקוף)
- אין צורך לגעת בקוד — המערכת מזהה את הקובץ אוטומטית לפי ה-`id`.
- רכיב ללא תמונה יציג fallback נקי: ריבוע בצבע הקטגוריה עם אייקון הקטגוריה.
- מומלץ תמונה מרובעת בערך (יחס ~1:1) על רקע שקוף/לבן, לפחות 400×400px.

> בסביבת פיתוח (`next dev`) קובץ חדש מופיע אחרי רענון הדף. ב-build הרשימה נצרבת בזמן הבנייה.

הצגת התמונה מתבצעת אוטומטית ב: כרטיס רכיב, עמוד הרכיב, ושורת ההשוואה.
